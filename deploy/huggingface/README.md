# VoxShield API

The backend of VoxShield (speech-to-text, scam-intent and synthetic-voice checks, and Live Call Protection signaling).
The web app is hosted separately and calls this Space at `https://<this-space>.hf.space/api/v1`.

* Liveness: `/api/v1/health`. Models loaded: `/api/v1/ready`.
* Audio is analysed in memory or in temporary files that are deleted after each analysis; nothing is stored.
* One container, one worker: live-call rooms are kept in memory, so a restart ends every call in progress.

This folder is generated by `deploy/huggingface/stage.sh` from the VoxShield repository; edit the repository, not this copy.
